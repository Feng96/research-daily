核心结论与下一步优先方向
本轮实验的核心判断与下一步

本页解释已经冻结选型后取得的留出结果，不改变方法、权重或阈值。终审状态以主报告为准。

1. 局部点云判别是目前最明确的收益来源。
主流程预选方法为 graph_support_mean3_residual。同一64栋×12条件中，原始基线限幅垂直损失 1.447056m，预选方法 0.934467m，降低 35.4%；clean64栋损失变化全为0。23个原生失败均为very_sparse，与raw同一批槽；745个原生成功中3个未通过1mm边关联诊断，不能宣称所有输出水密或通过完整几何有效性认证。主收益来自成功模型几何改善，不是提高生成率。这个指标包含失败/缺覆盖的10m罚分，并非通常成功模型MAE。plain graph相对global改善49.45mm，探索性建筑bootstrap95%区间[-86.02,-18.44]mm。自动3DBAG教师与人工观测污染的恢复结果不能当美国实测精度。

2. 加复杂模块需要逐项证明收益。
法向头与组合辅助头相对同一plain graph的留出差异区间均跨0。预选复杂流程相对plain graph只改善约5.33mm，独立探索性区间[-22.43,+15.70]mm；它包含不同训练损失和三模型集成预算，不能宣称复杂融合/辅助监督已被证明优越。单seed残差veto在这个留出集有约14.94mm的小改善，尚需匹配重复和多重比较解释。保守路由在dense_canopy几乎全部回退，丢失大部分筛点收益，说明总保留比例与native是否成功不足以代理屋面风险。

3. 去树与补缺口应分开，再由空间风险决定是否修补。
独立16栋×6侧实验中，源验证提前选定的支持度筛点+选择性补面loss为0.509157m，raw为1.875135m，clean16栋没有>2cm误伤。始终使用支持度筛点+线性补面的均值更低（0.363440m），但4/16干净屋面仍恶化>2cm；平均clean改善不能代替逐栋保护。选择性方案漏修部分稀疏/空洞。学习质量MLP相对简单点数规则只改善17.30mm，区间[-71.18,+14.78]mm跨0，源验证也未通过clean均值门槛。不能根据本次留出重新选它。
公开RoofDiffusion在纯空洞条件有价值，但当前冻结适配流程遇树冠时较差，侧实验整体不及线性补面。它有不同预训练预算和未知数据暴露，不能由本实验否定扩散方法或声称复现原论文benchmark。

4. 真实光学融合目前没有得到美国精度收益的证据。
波士顿/华盛顿5片区226实例、327008候选记录已跑14方法，各自223个LoD2输出、3个无几何，生成率完全相同。各方法确实改变不同的原始点子集，但语义late/late_aug/gated/SSL分别有219/217/194/189栋与raw掩码完全相同。源区分类准确率84.3%→约90.8%不能替代这里的屋顶精度。BackBay无标签EMA适配增加置信度不等于正确去树。波段/导出/特征重放审计通过；地面高度定义、物理密度、场景/每栋邻域、padding与光谱DN差异仍是需要控制的输入域因素。

建议优先的DL方向：可见性约束的局部屋面支持与重建风险预测，驱动选择性筛点和补面。
先用真实成对观测统一输入定义、密度/上下文和辐射增强；随后用点云局部编码器与空间影像特征，对点和候选平面预测观测支持、错误区域及修补风险。影像只代表可见表面，同XY树冠与树下屋顶不能直接共用一个tree标签。模型应在局部决定保留、去除、补面或弃权，并把原始观测与生成点分开记录。该新设计本轮未训练，也没有被证明新颖或有效；需胜过匹配backbone/增强/预算的late fusion、gating、点分类与简单覆盖/点数规则。

下一轮数据与验证优先级：真实AHN+逐年份PDOK+3DBAG可作配对弱监督候选；美国需被接受的独立屋面参考或人工测量核查集。若声称降低三维标注需求，要做匹配预算的标签学习曲线。当前500/3500单seed样本实验以及使用3500栋教师预训练的100栋质量选择器，都不能证明标注节省。新的模型应另留测试城市/建筑，本轮留出结果可以启发开发，不能反复用于调参后仍称独立测试。

统计范围：建筑为bootstrap单位、条件同时重采样；区间为探索性描述，未做多重比较校正，不覆盖训练seed变异、教师偏差或全国城市差异。多数native方法只用首个seed，三seed点诊断不等于所有native方法均做三次重建重复。论文贡献仍需在独立真实数据上证明机制或数据产品价值。

优先改进方向（待未来独立实验验证，本轮未证明这些新设计有效）：
  1. 先检验输入域匹配：统一height proxy/clip，匹配物理点密度、每栋候选点上下文和稀疏padding，再做真实光谱辐射增强/多源训练；这些收益不能归给新融合架构，简单整体均值匹配也不保证正确。
  2. 以最终重建风险和屋面支持度监督DL。对比点分类、aux法向/残差的结果，判断中间点指标能否转化为原生LoD2改善，避免仅追求分点准确率。
  3. 学习在哪里、何时补面，并保留有观测支持的干净屋面。将复杂屋顶的稀疏缺口与连续树冠区别处理；必须同时胜过线性/邻近补面和点数规则，且检验逐栋清洁误伤。
  4. 用真实光学可见性辅助支持度判别和目标适配，先补独立美国屋面GT；同XY树冠与屋顶不共享可见性，不能用源区分类准确率或无标签SSL置信度替代目标屋顶准确率。
  本轮为架构与流程探索，不能将“首次融合/首次去树/首次补面”作为创新结论；官方RoofDiffusion等已有相关方向。

方法解释与下一阶段 DL 设计假设
本轮实验方法说明

主重建比较：同一80栋源验证/64栋留出建筑，各12种条件，全部经过同一冻结Roofer后端。

raw：保留全部候选原始观测。
geometry：固定阈值和局部几何筛选参考。
global_cls_hard：PointNet-style全局点特征分类器，按源验证阈值保留屋顶点。
graph_cls_hard：固定一次kNN邻域并复用两层EdgeConv-style局部图，单屋顶分类目标。
graph_reweight_hard：同局部图，屋顶正类权重4，未增加法向/残差目标。
graph_normal_hard：局部图分类，额外只在真屋顶点上监督法向。
graph_support_balanced_hard：正类权重1，额外监督真屋顶及污染点下方屋面的法向/垂直残差。
graph_support_hard：正类权重4，额外法向/残差监督。
以上hard只使用屋顶概率筛选原始点，法向/残差输出没有直接进入后端。其差异可能通过共享特征训练影响概率，但不是直接生成了新屋面。

graph_normal_guard / graph_support_guard：对应模型的hard集合并上满足冻结平面支持规则的观测点，尝试恢复被误删的屋顶点。
geometry_support_guard：仍用graph_support屋顶概率和hard集合，但平面支持时使用原始观测估计的局部法向；这个名字不代表只用了geometry参考掩码。
weighted_ransac_support：用DL概率加权三点采样提出支持平面，SVD拟合不带权；有支持平面时对hard作交集，无支持平面时回退hard。流程还包含接受/组合阈值，不能单归因于加权采样。
residual_veto：从hard中去掉高屋顶概率却预测大垂直残差的点。

graph_cls_mean3_hard / graph_support_mean3_hard：对应三次随机训练的屋顶概率均值与各自校准阈值均值作筛选。
graph_support_mean3_abstain：三seed分歧高时保留观测，不把这种点强制删掉。
graph_support_mean3_guard：用三seed均值的法向及屋顶概率做平面支持保护。
graph_support_mean3_residual：三seed均值下加入残差veto，同时限制残差分歧。
三seed集成不等于单模型同计算预算，均值阈值也不继承单模型99.5%屋顶点保留保证。

observation_router_safe：候选为mean3_guard，观测数、保留比例、凸包支持或分歧规则不通过时回到raw；safe只是实验名，不表示逐栋风险保证。
observation_router_geometryfallback：候选为mean3_residual，观测规则不通过时回到geometry。
路由方法必须同时查看实际DL激活比例与回退比例，不能把大量回退到raw的干净屋顶当成DL纠错成功。

global_small_basic_hard / global_small_diverse_hard：500栋教师、基础/丰富污染混合的全局分类器。
global_large_basic_hard / global_cls_hard：3500栋教师、基础/丰富混合。四组匹配优化步数、只用单seed，混合也改变clean/sparse相对比例。
global_height_only_hard：把点级XY通道置零，仍保留由XY跨度计算的归一化尺度，不是完全没有XY信息。
global_relative_xyz_hard：只移除分类器的离地高输入通道，保留相对XYZ；原生重建仍使用共同地面和世界高程。其设计受到已查看的美国目标协变量统计启发。

补面侧实验：独立10栋源验证/16栋留出，各6种条件，不能与主比较均值交叉排名。
original_raw_native：相同侧实验队列上的原始观测重建。
raster_nearest_native / raster_linear_native：按冻结格网最近邻/线性插值后重建。
pretrained_roofdiffusion_native：官方公开预训练权重、冻结高度图适配器后重建；不代表原论文benchmark复现。
hybrid_geometry_linear_native / hybrid_global_cls_linear_native / hybrid_graph_support_linear_native：先筛选原始点，再用保留点线性补面、凸包外最近邻补值，然后重建。
hybrid_global_cls_selective_native / hybrid_graph_support_selective_native：删点比例≥5%才采用相应hybrid；否则原始原生重建失败时用未筛选线性补面，其余保留raw。
learned_quality_router_native：18维可观测特征输入三seed小MLP，预测raw/linear/global-hybrid候选代价分数再选择；未校准为期望风险，当前训练使用100栋教师但其点分类器预训练使用3500栋。
support_count_router_native：独特点数≤64用linear，否则DL删点比例≥5%用global-hybrid，其余raw。用于检查学习选择器是否只是学到了点数规则。
所有补出的格网点均为预测/插值，不是新测得的LiDAR回波。

真实NAIP/3DEP：固定226实例、14方法，只比较运行表现与原始点保留，没有独立目标准确率GT。
teacher_*为受控教师训练的分类器/集成筛点迁移到真实观测；relative_xyz是上述输入通道控制。
semantic2_point / late / late_aug / gated分别为真实ISPRS标签训练的纯几何、光谱late fusion、匹配增强late fusion、同增强逐点标量门控。
光谱只使用实测R/G/NIR及其手工8维特征，尚非空间影像CNN；mixed hedge/fence类别不等同纯树木。
semantic2_gated_ssl为监督源区重放＋BackBay无标签EMA伪标签一致性适配；semantic2_gated_ssl_guard额外并入geometry保留的原始点。
legacy_image是此前实验的光学参考，不计入本轮41个新训练模型。

准确公式、参数、sha与逐实例结果见冻结JSON和独立审计；本文只是便于阅读的方法释义，不替代协议。

建议的下一阶段：观测支持的屋面可信度与选择性补面

性质：研究假设与后续实验设计。本轮没有训练以下新架构，也没有证明它优于现有方法。最终留出结果与独立审查应优先于本建议。

为什么值得试：
本轮源验证中，固定局部图的点分类已明显改善受控污染后的重建，但额外法向/残差头没有稳定胜过分类器。残差veto的微小平均改善，其建筑配对区间跨零。DL筛点后补面能大幅改善遮挡样本，却会损伤干净屋面；选择性补面保护干净屋顶，同时漏修一部分有支持但稀疏/缺口的屋顶。学习质量选择器虽降低平均损失，源验证的干净屋顶保护未通过，而且仍需与简单点数规则竞争。

这些是源验证观察，不是最终城市结论。尤其不能把support hybrid比global hybrid的差异单独归因于辅助监督：backbone、类别权重、辅助头都不同，补面实际只用pRoof。

输入：
1. 原始真实点云XYZ、离地高、局部邻域几何、回波/强度（仅在可用、跨项目定义一致时使用）。保留未分类点和原始索引。
2. 经过配准且有采集日期记录的光学影像块。影像编码器输出空间特征；点通过投影从相应像素/邻域取特征。NIR若缺失，应显式标识，不能把不存在的波段补造成实测。
3. 独立的建筑足迹及其配准残差/边界不确定性。足迹偏移不能被默认为树木或建筑缺失。

输出：
1. 点的屋顶/植被概率及有效观测支持度。
2. 基于原始点提出的候选平面可信度、支持区域和边界不确定性。
3. 仅针对缺乏观测支持的区域给出补面建议及不确定性；保留原始观测与预测点的身份区别。
4. 选择保留原生重建、局部修正、补面或弃权。输出要能解释在哪个面、哪些原始点上发生了改变。

模型与损失：
可先采用局部点编码器+影像CNN/Transformer，融合点对应的空间影像特征，再对候选平面做集合聚合。这个组合本身不是新颖性声明。
训练应同时优化屋顶/植被判断、平面支持与重建风险。平面内观测一致性、干净屋面保护、补面区域约束可作为候选损失；离散原生重建若不可微，可先回归固定重建器的候选代价与错误区域，或采用可微平面拟合作为代理。必须用原生LoD2输出复核代理是否有效，不能仅汇报代理损失。
不确定性需用独立校准区检验；本轮raw softmax≥0.9只是伪标签启发式，尚未建立校准保障。

更具体的待验证机制：可见性约束的融合
同XY的树冠回波与树下屋顶回波可能共享同一正射像素，颜色只代表可见表面。影像的tree标签不能沿竖直方向无差别传给所有点。可将点相对于局部上包络的高差、邻域层次、扫描几何（可用时）与影像配准不确定性输入一个可见性/可靠性分支，再决定该点使用多少影像证据，并对候选屋面聚合真实点支持。该设计不是已经验证的创新，也不能断言其他领域没有visibility-aware fusion；必须在相同编码器/增强/预算下对比简单late fusion、现有逐点标量gating与新增可见性机制。真实树下屋面GT比仅模拟随机缺点更重要。

依据本轮真实输入审计，先做的最小迁移消融（本轮未运行、不可宣称已有效）：
1. 统一语义网络的height proxy定义/clip，或做relativeXYZ去显式离地高通道控制；后端的真实地面高程另行保留。
2. 匹配源与目标的候选点上下文、物理点密度、稀疏padding。当前source全场512近邻，BackBay每栋高度筛选候选点；57/60栋不足512，padding18294/46080。源训练应加入匹配物理密度的点丢弃/重采样和有效点掩膜，对比相同架构/预算，而不能把这些输入差异的收益归给融合架构。
3. 处理跨传感器光谱DN差异。13项重放与服务原像元核对已通过，NAIP默认/None/冻存DN一致，不能修改成更好看的颜色来追求去树结果。DN/255不是校准反射率；可检验多场景真实配对训练、合理辐射增强与可见性可靠性，但目标类别比例不同，简单匹配两域整体均值不能保证正确。
4. 再检验上述可见性/平面支持度/选择性补面机制，并与已修正迁移基线比较。监督源重放+EMA的置信度上升本身不构成目标准确率证据。
